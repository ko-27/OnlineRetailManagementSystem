\# Online Retail Management System



\## Project Overview



The Online Retail Management System (ORMS) is a modular software project designed to support common online retail operations such as product management, user management, shopping cart processing, payment processing, order processing, and inventory management.



\## Project Objectives



\- Organize the application into independent functional modules.

\- Use Git for distributed version control.

\- Use GitHub for remote repository management and collaboration.

\- Use feature branches for parallel module development.

\- Demonstrate repository synchronization using Git Fetch, Pull, and Push.

\- Use Jenkins to implement Continuous Integration.

\- Automatically trigger Jenkins builds whenever new code is pushed to GitHub.



\## Modules



1\. Product Catalog

2\. User Management

3\. Shopping Cart

4\. Payment Gateway

5\. Order Processing

6\. Inventory Management



\## DevOps Workflow



Developer → Local Git Repository → GitHub → Jenkins → Automated Build



###### Continuous Integration



This project uses Jenkins to automatically validate changes pushed to the main branch.
